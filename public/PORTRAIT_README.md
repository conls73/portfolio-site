# Portrait Image Setup

## How to Add Your Portrait

1. Save your professional portrait image as `portrait.jpg` or `portrait.png` in this folder (`public/`)

2. **Recommended specifications:**
   - Aspect ratio: 3:4 (width:height)
   - Suggested size: 400-600px wide
   - File format: JPG (smaller file size) or PNG
   - File size: Keep under 500KB for optimal performance
   - Background: White or soft light gray (matches the site design)

3. The image will appear in the hero section with:
   - Rounded corners
   - Soft shadow
   - Subtle parallax effect on desktop
   - Responsive layout on mobile

## Example Dimensions

- Small (good for mobile): 400x533px
- Large (good for desktop): 600x800px
- Extra large (retina displays): 1200x1600px

## File Size Optimization

Before adding your image, optimize it:
- Use an online tool like TinyPNG or Squoosh
- Aim for ~200-300KB JPG
- Maintain high quality while reducing file size

## Current Status

If you see a broken image in the hero section, it means the portrait file hasn't been added yet. Once you add `portrait.jpg` or `portrait.png` to this folder, it will automatically appear.

The site will look great with any professional headshot - just make sure it matches the Apple-clean aesthetic!
